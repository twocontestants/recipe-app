# Quickstart: Remove public recipes

1. Sign out. Open `/recipes` → redirected to login (no public catalog).
2. Sign in as cook A. Recipes list is only A’s recipes; no “Include public library”.
3. Open a recipe → no Make public / Make private.
4. Planner add-recipe picker → only A’s recipes.
5. As moderator in Settings → role options are Cook / Moderator (no Publisher); intro text does not describe public sharing.
6. `npm test` passes.
