# Quickstart: Calendar-date dinners

## Automated

```sh
npm test
```

Expected: `lib/plannerDate.test.ts` plus existing planner/sheet/shopping tests.

## Manual

1. Open the planner in Australia. This week’s dinners are on the same days as before the deploy.
2. Add a dinner on Wednesday. Reload — still Wednesday.
3. Generate a shopping list for this week — those recipes are there.
4. Open a Thursday note, edit, flip away and back — still Thursday.
5. Hold-drag a dinner to Saturday — it stays Saturday after reload.
